# Family Finance

A personal finance web application for tracking shared household expenses, income, and currency conversions, with reporting and receipt-processing features.

## Features

- **Shared household records:** a shared Supabase-backed database for household finance entries.
- **Expense tracking:** categorize purchases and review transaction history.
- **Financial analytics:** view expense breakdowns, compare months, and track budgets.
- **Currency tracking:** record currency exchange rates and monitor USD purchases and balances.
- **Receipt processing:** upload or photograph receipts and review extracted purchase details.
- **Product tracking:** record product names, quantities, weights, and unit prices.
- **Mobile-friendly interface:** designed for use on phones and desktop browsers.

## Technology

- HTML, CSS, and JavaScript frontend
- Supabase for shared data storage
- Browser-based charts and financial reporting
- Receipt recognition integration

## Project motivation

Family Finance was created to simplify household budgeting across currencies and devices, reduce manual entry from receipts, and make spending trends easier to understand.
